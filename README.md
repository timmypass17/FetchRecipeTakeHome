### Focus Areas: What specific areas of the project did you prioritize? Why did you choose to focus on these areas?
I choose to prioritize making the code clean and maintainable by following MVVM and SOLID principles. I try to create separate classes for different features of the app. I choose to focus on these areas because it makes it easier to work on the app in the future to make it great! I also made sure to handle cases where data fetching could go wrong and handle errors gracefully by showing the user approriate texts.

### Time Spent: Approximately how long did you spend working on this project? How did you allocate your time?
I spent around 4-5 hours. I adopted Test Driven Developement and created unit tests firsts for features of my app (e.g. fetching recipes). And then I polish the UI and organize everything using MVVM.

### Trade-offs and Decisions: Did you make any significant trade-offs in your approach?
I spent most of the time making the app efficient such as learning how to apply image caching using URLSession.

### Weakest Part of the Project: What do you think is the weakest part of your project?
There were some things I didn't implement in this app such as localization and accessibility. If I had more time I would've also learned to embed the youtube videos and website url directly in the app instead of redirecting the user using safari.

### Additional Information: Is there anything else we should know? Feel free to share any insights or constraints you encountered.
I made the app more fun by adding flag emojis for cuisines and making a "Recipes of the Week" card view. I tried to utilize all the data in the recipe json to make the app the best it could be.
